# 文案册（2026-07-27 定稿）

全应用用户可见文案的唯一口径。改任何一句话，先改这里，再改代码；
Playwright 验收规格按本册断言。出处以组件为单位（行号会漂，不记）。

## 家法

- 全中文；零 emoji；短句，笃定，不打官腔。
- 揭示的那道菜叫「这一顿」，永远不叫「今日推荐」。
- 五档情感刻度的正名：拉完了 / NPC / 人上人 / 顶尖 / 夯。徽标与刻度只用
  标签，不见数字。入池场景只开上三档，下两档只在评分回显与评分刻度出现。
- 品牌问号「？」是签名视觉件（陶色 span），不算文案，但它出现的句子把它
  当句读用：「今天吃什么？」「池子还空着？」。
- 服务端错误信封的 message 原样渲染，前端不复写；前端只有两条兜底
  （见「兜底错误」）。

## 登录 / 注册（LoginPage）

| 文案 | 语境 |
|---|---|
| 今天吃什么？ | h1（问号陶色） |
| 进来，定这一顿。 | 副标题 |
| 用户名 / 密码 | 表单 label |
| 登录 | login 模式提交；register 模式的切换动作 |
| 注册 | register 模式提交；login 模式的切换动作 |
| 还没有账号？ / 已有账号？ | 模式切换引导 |
| 至少 8 个字符。 | 注册模式密码 hint |
| 显示密码 / 隐藏密码 | 密码可见性按钮 aria-label |
| 登录过期了，再进来一次。 | 会话过期横幅 |
| 输入用户名 / 输入密码 | 空值指路 |
| 正在加载 | 会话加载态 aria-label |

预校验错误（validation）：

- 用户名须为 3–32 个字符
- 用户名只能包含字母、数字、下划线或连字符
- 密码至少需要 8 个字符
- 密码不能超过 72 个 UTF-8 字节

## 主界面（HomePage）

**就绪态**：这一顿，交给池子。 / 合适的那道会自己站出来。 / 按钮「开始这一顿」。

**揭示**：标签「这一顿」；discovery 徽标「池子外的新尝试」；按钮
「换一道 · 剩 {n} 次」「就吃这个」；信息小字「约 {n} 分钟」「难度{一~五}星」。

**额度耗尽三出口**：换菜次数用完了。这顿的结局你来定： / 「这顿不吃了」
「亲自点一道」「就吃这个」；手选加载「正在翻池子……」。

**空池欢迎**：池子还空着。 / 放几道你爱吃的进来，这一顿才有得挑。 /
「经典起步包 · {n} 道家常菜入池」「自己去挑菜」。

**待评分拦截**：先说说上一顿。 / 好不好吃，一句话的事；说完就能开新的一顿。

**信息栏**（桌面）：左「池子」「{n} 道」「去管池子」；右「最近吃过」
「这里会记下你吃过的每一顿。」「看全部」。加载态 aria-label「正在看这一顿的状态」。

## 池子页（CandidatePoolPage）

- 池子（h1）；{n} 道菜备着。点档位徽标可以改喜欢的程度。 / 这一顿只会从池子里挑。
- 空态：池子还空着？在下面搜你爱吃的，一道道放进来。
- 加菜：往池子加菜（h2）；搜菜谱库里的名字，入池默认「顶尖」，之后随时改。；
  placeholder「比如：番茄」；按钮「搜索」「入池」「已在池里」。
- 搜索无果：菜谱库里没有这道。换个写法试试，比如只搜两个字。
- aria-label：搜索菜谱库 / 改 {菜名} 的档位 / 把 {菜名} 移出池子 / 正在翻池子。

## 历史页（HistoryPage）

- 吃过的（h1）；最近的每一顿都记着。想补一句评价，随时。
- 空态：还一顿都没吃过？回主页，开一顿。
- 小节：最近吃过 / 最近爱吃；记录行标注「新尝试」（discovery）、
  「亲自点的」（hand_pick）；加载态「正在翻记录」。
- 评价入口一菜一口，只在每道菜最近一条未评记录上出现：菜不在池内时是
  按钮「补一句评价」；已在池内时不催评，改为现役档位徽标（虚线描边，
  aria-label「改 {菜名} 的评价」），点开五档刻度可改，下两档仍走剔池。
  更早的同菜记录留白。

## 菜谱页（RecipePage）

- 缺参错误：地址少了菜名，回主页重新开一顿吧。
- 页头小字：{品类} · 约 {n} 分钟 · 难度{一~五}星 · 约 {n} 大卡。
- 图：alt「{菜名} 成品图」「{菜名} 步骤图」；小节「步骤图」（h2）。
- 页底：开始下一顿；加载态「正在翻菜谱」。

## 404（NotFoundPage）

这里什么都没有。 / 地址不对。回主页，接着定这一顿。 / 「回主页」。

## 页头壳（AppShell）与通用件

- wordmark「今天吃什么？」；导航「池子」「吃过的」；「登出」（aria-label + title）；
  跳转链接「跳到主要内容」（sr-only）；主导航（nav aria-label）。
- Notice 重试按钮「再试一次」；RequireSession 加载态「正在恢复登录状态」。

## 兜底错误（lib/copy.ts）

- 网络不通，检查一下再试
- 服务暂时不可用，稍后再试

## 备案：已知口径分化（定稿时有意保留）

1. discovery 的两处叫法：揭示徽标「池子外的新尝试」（打明牌要说全），
   历史行标注「新尝试」（行内求短）。层级分化，非笔误。
2. 历史入口「吃过的」（页名/导航）与「最近吃过」（小节名）：页与节的关系。
3. 「开一顿」动词族按语境松紧：开始这一顿（主 CTA）/ 开始下一顿（菜谱页底）/
   回主页，开一顿。（历史空态）/ 回主页重新开一顿吧（菜谱缺参）。
4. 「NPC」是刻度正名的一部分，属有意的拉丁字符特例；「UTF-8 字节」是唯一
   工程口吻外露的文案，随 bcrypt 上限存在，暂不遮。
